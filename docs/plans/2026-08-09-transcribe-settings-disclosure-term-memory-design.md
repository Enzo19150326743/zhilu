# 转写设置补充信息与术语记忆收敛设计

## 目标

- 让“补充识别信息”看起来是可操作入口，而不是普通分隔标题。
- 让多人节目能够明确找到说话人信息，同时保持姓名和身份非必填。
- 将术语能力从文件管理器收敛为本次输入、最近使用和本期已选。

## 交互设计

### 补充识别信息

- 折叠入口使用粗黑边框、品牌红错位阴影和明确的展开图标。
- 展开后先展示独立的“说话人（可不填）”区块，再展示内容标签。
- 说话人区块使用独立描边和更明确的添加动作，不再混在标签下方。

### 多人节目

- 选择“双人访谈”或“多人聊天 / 圆桌”后立即更新节目结构和默认角色，不强制展开补充区域。
- 节目结构下方显示“已按对应结构识别”和“补充说话人（可选）”入口。
- 点击入口后展开补充区域、定位到说话人区块并聚焦第一个姓名输入框。
- 用户已经填写的说话人内容不得在切换节目结构时被静默覆盖；只有当前内容仍为系统默认值时才替换为新结构默认值。

### 术语记忆

- 转写弹窗只保留本期术语输入、最近使用和本期已选。
- 转写成功后继续由后端自动记录使用次数和最近使用时间。
- 删除文件夹、智能视图、搜索、批量选择、移动、重命名和批量删除等完整管理界面。
- 保留现有本地术语数据，不执行破坏性数据迁移。

## 验证

- 桌面端验证补充入口的折叠和程序化展开。
- 验证双人、多人结构无需填写姓名也能提交。
- 验证填写后的说话人不会因结构切换被覆盖。
- 验证最近术语可选择、本期术语可新增和移除。
- 运行生产构建与现有桌面端 E2E。
