# 知录桌面端体验与品牌内视觉优化设计

## 目标

将当前偏产品海报的页面收敛为可持续使用的桌面端知识工作台，让用户更快完成“粘贴链接、打开最近档案、阅读总结、查看原文、摘录与导出”。本轮不处理手机端，不改变后端业务合同。

## 已确认边界

- 内容工作台顶部继续保留“提取内容”文案与现有动作。
- 红色继续作为品牌色，用于主操作、选中状态、关键引用和少量品牌块。
- 粗黑边框与错位阴影继续作为“新粗野主义 + 文案台”的核心识别特征。
- 删除无实际信息职责的英文小标签和装饰编号，但不删除真实平台、格式、状态等必要信息。
- 省略号操作按钮改成含义明确的共识图标；默认只显示图标，悬停或聚焦时显示中文说明。
- 可以调整字体系统；不满意时能够基于改造前 Git 检查点撤回。
- 不改移动端，不扩展下载器、RAG、问答历史等产品范围。

## 设计方向

这是保留品牌的定向演进，不是视觉重做。设计参数为：变化度 6、动效 3、信息密度 6。

- 视觉基础：暖纸色背景、近黑文字、品牌红、锐利直角、粗黑边框、错位阴影。
- 字体分工：标题和长内容使用适合中文阅读的衬线字体；按钮、导航、列表和状态使用清晰的中文无衬线字体；等宽字体仅保留给时间码和技术格式。
- 强调纪律：每个操作区域只保留一个高强调动作；红色和阴影表达真实层级，不作为每段内容的装饰。
- 交互反馈：图标按钮有稳定点击区域、hover、active、focus 和 tooltip；不会因 hover 出现文字而挤压内容。

## 页面结构

### 首页

- 压缩品牌宣言区，让输入链接和最近档案进入首屏任务范围。
- 推荐内容从大幅展示改为紧凑入口；已有档案时不阻断最近档案。
- 删除常驻的流程编号和无职责英文标签；流程反馈只在真实解析任务发生时展示。
- 最近档案保留资源身份、标题、来源、状态和时间；标题过长时保持稳定两行并避免正文式内容撑高列表。

### 内容工作台

- 继续显示顶部 URL 输入和“提取内容”。
- 来源栏在桌面端成为可持续参考的粘性侧栏；下载格式保持辅助职责。
- 内容标签栏在长内容滚动时保持可见。
- 打开具体内容时不再在工作台底部重复渲染首页“最近档案”。

### 总结

- 保留红色重点、引用和选中态，减少章节序号、重复标签和英文装饰。
- 对关键词做大小写、空格和常见变体去重，并限制首屏标签数量。
- “重新生成知识稿”降为次级管理操作，避免压过阅读和导出。

### 内容文本与摘录

- 原文是主对象，进入标签后优先可见。
- AI 摘录和摘录草稿移入桌面端辅助栏或可折叠区域，不再把原文推到首屏之后。
- 摘录默认展示，用户明确触发后才进入编辑态。
- 保留校对稿和原始稿切换；重新转写作为低频管理动作。

### 思维导图与问答

- 导图优先获得宽画布，并提供明确的适应、缩放和全屏图标操作。
- 问答空状态提供基于当前内容的示例问题，删除重复的“当前模式”说明块。
- 问答输入在对话增长后仍保持稳定位置。

- 页面编排：`frontend/app/page.tsx`、`frontend/components/WorkspaceViews.tsx`

- 工作台外壳：`Header.tsx`、`UrlInput.tsx`、`VideoPreviewCard.tsx`、`FormatSelector.tsx`、`AiTabs.tsx`
- 内容区：`SummaryTab.tsx`、`TranscriptTab.tsx`、`TranscriptNoteWorkflow.tsx`、`MindmapTab.tsx`、`QaTab.tsx`
- 视觉系统：`frontend/app/globals.css` 和现有 Tailwind 配置

## 数据与状态

- 不改变解析、总结、转写、下载和问答接口。
- 不复制后端数据；标签去重和展示数量属于前端派生视图。
- 现有请求忙碌状态、失败状态和用户输入保持原边界。
- 首页集合与当前详情继续使用既有控制器状态，只调整渲染职责。

## 验证

- 运行现有 helper 测试、TypeScript/Next.js 构建和桌面端 E2E。
- 使用桌面端 1280×720 浏览器检查：首页首屏、打开最近档案、四个内容标签、长内容滚动、图标 tooltip 和控制台错误。
- 不执行手机端验收；最终明确报告未验证范围。
