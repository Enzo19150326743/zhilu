# 输入聚焦与重复转写删减设计

## 目标

- 删除链接栏和问答输入栏聚焦时的红色双层描边。
- 保留克制且可辨认的输入状态，不新增装饰性高亮。
- 精简问答范围说明。
- 删除已有完整转写稿后的再次转写入口和前端分支，同时保留 shownotes 首次生成转写稿。

## 界面设计

- 工作台链接栏聚焦时继续使用原有黑色粗边，输入框不再显示红色焦点轮廓，外层容器不再切换品牌红边框。
- 问答输入框聚焦时只把自身细边框加深为黑色，不绘制额外外框。
- 问答说明改为“仅根据当前内容回答，不确定处会说明。”
- 内容文本已有完整转写稿时不显示“重新转写”；shownotes 和无转写稿状态继续提供首次生成转写稿入口。

## 状态与数据流

- `canTranscribe` 在已有完整转写稿时为 `false`，从共享状态源阻止重复入口，而不是只隐藏单个按钮。
- 转写工作流只处理首次生成：完成后继续自动生成总结；删除“保留旧版本并对比”的重复转写成功分支。
- 既有历史数据中的多版本查看能力暂不删除，避免旧记录失去读取能力。

## 验证

- 桌面端检查两个输入框聚焦时不存在品牌红轮廓。
- 检查已有完整转写稿不显示“重新转写”，需转写记录和 shownotes 仍可生成转写稿。
- 运行前端辅助测试、桌面端 E2E 和生产构建。
