# 云端 ASR、结构化摘要与思维导图设计

## 目标

在保留本地 `faster-whisper` 默认路径的基础上，增加由用户手动选择的
Fun-ASR-Flash 云端转写；同时完善现有结构化摘要展示和 Markmap 交互。
本轮不引入 RAG、向量库、React Flow 或本地 FunASR 运行时。

## ASR 数据流

媒体链接仍先经过现有平台解析与下载。默认路径继续直接使用本地 Whisper；
云端路径使用 ffmpeg 将实际下载文件统一转换为 16kHz 单声道 Opus，按 270 秒、
2 秒重叠切段后，最多并发提交 3 段到 `fun-asr-flash-2026-06-15`。

云端结果使用返回的句子和词时间戳换算为全局时间，并按重叠时间窗口去重。
节目结构、标签、说话人和术语会被压缩到 400 字符内作为识别上下文。可重试错误
最多重试两次；最终失败时明确报错，不静默回退本地模型。

本地与云端原始稿都继续进入 DeepSeek 校对。约 3500 字符是一次校对请求的批量，
所有批次都会处理，因此不是全文读取上限。总结和 QA 始终使用完整转录，并保留
120,000 字符的显式请求上限。

## 前端与接口

`POST /api/transcribe` 增加默认值为 `local_whisper` 的 `asr_engine`。转录弹窗展示
本地与云端两个选项；云端未配置时禁用，并说明数据上传和按量计费。云端失败后
提供切换本地重试，不自动改变用户选择。

结构化摘要继续由一次 DeepSeek 请求同时生成摘要和导图。前端展示现有的结构化
分析、主题、关键词、内容边界和应用线索，使用安全的轻量 Markdown 解析，不注入
HTML。Markmap 增加缩放、适应、复位、节点高亮与画布提示，保留现有 Markdown
合同，不支持自由拖动单个节点。

## 失败边界与验证

云端密钥缺失、限流、超时、片段失败都返回明确错误；临时音频始终清理。旧客户端
不传 `asr_engine` 时继续走本地转写。测试覆盖多媒体格式转码、片段时长、并发排序、
重叠去重、上下文长度、失败不回退、3500 字符校对批量、完整总结/QA输入和导图交互。
