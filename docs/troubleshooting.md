# 常见问题排查

## 页面提示后端不可达

确认后端窗口仍在运行，并访问：

```text
http://127.0.0.1:8000/api/health
```

如果端口被其他程序占用，启动器会拒绝结束不属于当前项目的进程。请先关闭占用 8000 或 3000 端口的程序。

## 总结或问答返回本地结果

1. 检查 `backend/.env` 是否存在。
2. 检查 `AI_API_KEY`、`AI_BASE_URL` 和模型名。
3. 修改配置后重启后端。
4. 查看后端窗口中的安全错误提示，不要把 Key 粘贴到 Issue。

AI 服务不可用不会阻止基础解析；系统会保留本地降级结果。

## B 站只有 480p

这通常表示平台当前匿名公开格式上限，并不一定是前端筛选错误。登录态只能读取账号本身有权访问的格式，也不保证固定 1080p。

如果刚修改 Cookie 配置，请重启后端并点击“重新提取”，避免继续读取旧 SQLite 缓存。

## 没有字幕或内容文本

平台可能没有公开字幕。打开“内容文本”，按需生成本地 AI 转写稿。第一次使用 Whisper 时可能下载模型。

## Whisper 模型不可用或转写很慢

- 检查 `ASR_WHISPER_MODEL` 是否是有效模型名或本地目录。
- 先使用 `base + cpu + int8` 验证链路。
- GPU 显存不足时允许自动回退 CPU。
- 长媒体会显著增加转写时间，第一次先测试短内容。

## 小宇宙解析失败

- 确认链接是公开 `/episode/...` 单集页面。
- 公共 RSSHub 不可用时，系统会尝试公开网页解析。
- Shownotes 只是节目说明，不代表完整音频逐字稿。

## 下载或音视频合并失败

检查系统能否找到 ffmpeg，或在 `backend/.env` 设置 `FFMPEG_LOCATION`。平台临时拒绝、格式过期或地区限制也可能导致失败。

## 修改配置后没有变化

配置在后端启动时读取。关闭并重新启动后端，然后点击“重新提取”。普通解析会优先复用本地历史缓存。

## 提交 Issue 前

可以附上：

- 操作系统、Python 和 Node.js 版本
- 媒体平台和公开链接类型
- 可以公开的错误代码和脱敏日志
- 是否配置 AI、ffmpeg 或本地 ASR

不要附上 API Key、Cookie、完整 `.env`、本地绝对路径、私人媒体全文或 Obsidian Vault 内容。
