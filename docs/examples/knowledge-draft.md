# 从公开媒体到本地知识稿

## 一句话结论

把视频与播客中的信息整理为结构清楚、来源可追溯、能够继续编辑的本地 Markdown 知识稿。

## 核心观点

- 媒体解析只是入口，最终产物应当能够脱离应用长期保存。
- 用户确认的“我的整理”与未确认 AI 候选需要明确分开。
- 来源链接、作者和处理日期应随知识稿一起保留。

## 可借鉴的方法

- 先获取公开媒体的字幕、Shownotes 或本地转写。
- 先读结论和关键观点，需要时再核对当前转写稿中的原文依据。
- 把确认后的内容加入“我的整理”，再导出普通 Markdown 文件。

## 内容脉络

- 获取可用内容文本。
- 提炼结论、观点、理由、方法和适用条件。
- 核对依据、继续编辑并导出。

## 我的整理

### 整理 1

真正有价值的不是看过多少内容，而是留下多少可以继续使用的知识。

- 摘录说明：用于演示“我的整理”的合成文本，不来自真实媒体。

## 内容边界与待核实信息

- 本文件是公开合成示例，不包含真实转写稿或第三方全文。
- 外部作者观点只代表对应来源，不自动等于用户观点。
