# 从公开媒体到本地知识稿

## 一句话摘要

把视频与播客中的信息整理为结构清楚、来源可追溯、能够继续编辑的本地 Markdown 知识稿。

## 内容结构

1. 获取公开媒体的字幕、Shownotes 或本地转写。
2. 生成摘要、核心观点、行动建议和摘录草稿。
3. 将确认后的内容保存为普通 Markdown 文件。

## 核心观点

- 媒体解析只是入口，最终产物应当能够脱离应用长期保存。
- 用户确认摘录与 AI 候选摘录需要明确分开。
- 来源链接、作者和处理日期应随知识稿一起保留。

## 可靠原文摘录

> [!quote] 用户确认摘录
> 真正有价值的不是看过多少内容，而是留下多少可以继续使用的知识。

- 摘录说明：用于演示 Obsidian Callout 的合成文本，不来自真实媒体。

## 通用应用线索

- 将导出目录设置为 Obsidian Vault 内的固定子目录。
- 通过 YAML Properties 按平台、内容类型和关键词筛选知识稿。

## 内容边界与待核实信息

- 本文件是公开合成示例，不包含真实转写稿或第三方全文。
- 外部作者观点只代表对应来源，不自动等于用户观点。
