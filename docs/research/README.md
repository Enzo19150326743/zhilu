# 知录用户研究材料

这套材料用于完成 **15 份真实需求问卷 + 6—8 人远程可用性测试**。15 人是问卷样本，不等于 15 人都试用了产品。

## 你要按这个顺序做

1. 把 [01-demand-questionnaire.md](01-demand-questionnaire.md) 复制到腾讯问卷、问卷星或金数据；
2. 发出问卷，回收 15 份有效回答；
3. 根据问卷末尾的筛选表，选 6 人正式测试、2 人候补；
4. 按 [03-remote-test-moderator-guide.md](03-remote-test-moderator-guide.md) 准备电脑并预约腾讯会议；
5. 每测试 1 人，复制一份 [04-observation-record-template.md](04-observation-record-template.md) 并当场记录；
6. 测试结束后，让参与者填写 [02-usability-test-questionnaire.md](02-usability-test-questionnaire.md)；
7. 全部结束后，按 [05-analysis-and-resume-claims-guide.md](05-analysis-and-resume-claims-guide.md) 统计、改产品和写简历。

## 三条红线

- 联系方式单独保存，不要放进公开 GitHub 仓库；
- 结果没有发生前不要填写“认可人数、持续使用人数、完成率”；
- 问卷参与者只有实际操作过产品，才能计入“试用用户”。

原始问卷和观察记录建议保存在本地私有文件夹，例如：

```text
用户研究私有数据/
├── 问卷原始导出.xlsx
├── 试用者联系方式.xlsx
├── U01-观察记录.md
└── U02-观察记录.md
```

公开作品集中只放匿名汇总、真实截图和取得同意的匿名引语。
