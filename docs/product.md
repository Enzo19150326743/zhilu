# 知录产品说明

## 目标与使用者

知录是本地优先的公开视频与播客知识整理工具。学习者和内容创作者输入公开媒体链接，生成有来源依据的摘要，按需核对原文、编辑自己的整理内容，最后导出 Markdown。

核心路径：**提炼内容 → 核对与整理 → 导出知识稿**。下载原视频是辅助保存能力。

## 当前功能与规则

| 用户要完成的事 | 当前行为 |
|---|---|
| 处理一个链接 | 首页或工作台提交持久任务，后台依次解析、按需转写并总结 |
| 处理多个链接 | 一批接受 1～49 条链接，分享文案自动提取链接并去重；50 条整批拒绝 |
| 查看处理进度 | 查看服务端任务阶段、错误、取消和重试；刷新页面不丢失已提交任务 |
| 阅读结果 | 提供总结、思维导图、问答与内容原文；后台完成不替换正在阅读的其他文章 |
| 核对总结 | 观点可关联原文片段；引用与当前有效转写稿的指纹一致时才开放核对 |
| 整理笔记 | 从正文或 AI 候选加入“我的整理”，继续编辑并保存到本地 |
| 导出内容 | 导出通用 Markdown；默认包含总结和已确认整理，不输出未确认的 AI 候选 |
| 写入 Obsidian | 用户显式配置后可写入指定 Vault，默认只下载文件 |
| 回看内容 | 本地内容库提供筛选、加载更多、打开和删除；仍在处理的档案不能删除 |
| 无外部依赖体验 | 通过内置推荐数据查看工作台；获取远程封面仍可能需要联网 |

## 文本与 AI 边界

- 输入来源包括 B 站、抖音、小宇宙、小红书公开视频及 yt-dlp 可处理的其他公开媒体。具体可用性取决于平台公开接口，不能承诺全平台或所有链接成功。
- 平台字幕可直接作为完整文本；shownotes 是节目简介，不能冒充逐字稿。
- 缺少完整文本时，默认提炼任务使用本地 SenseVoiceSmall 补齐转写，再继续总结。依赖未就绪时明确失败，不切换其他语音模型。
- 可选 AI 校对保留原始稿；术语和人物说明用于校对，不注入声学识别。人物标签是文本辅助推断，不是声纹识别。
- 总结、问答与校对使用用户配置的兼容 API。未配置或调用失败时，以对应模块的原稿保留或本地降级规则返回，并标明状态。
- 问答只围绕当前内容，不建立跨媒体 RAG、问答历史或个人数字分身画像。

## 数据与失败处理

- SQLite、媒体下载和任务检查点留在本机；工具、凭据、浏览器资料放在被忽略的 `.local/`。
- 重试复用已保存的阶段结果；取消不删除已经生成的内容。
- AI 请求发出后若服务中断且结果是否保存无法确定，任务报告 `AI_RESULT_UNCERTAIN`，由用户决定重试，避免自动重复付费。
- 编辑后立即导出，应先保存最新整理，再生成导出文件。
- 本地优先不等于离线：媒体获取、模型首次下载及已启用的 AI 调用需要联网。

## 不属于当前主线

账号体系、支付、云端托管、浏览器捕获插件、完整下载器、主页采集、跨媒体全文检索、移动端投递，以及绕过登录、付费、私密或版权限制的能力。
