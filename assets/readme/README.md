# README 素材

保留项目原有的新粗野风格：米白底、黑色粗边框、硬阴影、砖红主色，以及少量黄、绿、紫色功能分区。

- 当前目录的 SVG 是可编辑的品牌与流程插图。
- `screenshots/` 只放当前 README 使用的真实界面截图；旧截图可从 Git 历史查看。
- 临时截图与排版预览放在被忽略的 `output/playwright/`，不提交到仓库。

## 截图要求

从正在运行的 Next.js 前端与 FastAPI 后端获取页面。不得用占位 HTML、修改 DOM 或模拟接口替换产品内容。

首页只截公开推荐内容与输入区域，避开个人历史。工作台使用应用自带的公开推荐内容，保留来源与“推荐摘要”等真实标识；不要用截图暗示重新执行过真实 AI 或转写。设置弹窗仅展示现有控件，不提交任务、不调用付费接口。

建议桌面视口宽 1440px；截图后检查文字、图片、滚动位置、隐私内容和浏览器报错，再替换 README 引用。需要窄屏复核时使用 390px。图片文件名按页面命名，不附带 `current`、`new` 或多个版本后缀。
